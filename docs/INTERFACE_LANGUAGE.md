# Interface language

The independent game uses English interface text regardless of the language
of the original disks supplied locally.

The five startup actions are **Create Your Deity**, **Conquest Game**,
**Custom Game**, **Load Game** and **Quit**. They retain the original font,
nineteen-cell rows, decoration, palette and click regions. Older exported
startup metadata is translated when loaded, so regenerating assets is not
required to change the visible labels.

The campaign briefing displays the opponent's six element experience values,
starting groups, population, movement speed and weapons. Internal campaign
author notes are retained as resource data but are not used as interface text.

The final congratulations scroll is also English. Its artwork, palette,
animation loop and PAL presentation timing remain unchanged.
